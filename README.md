## ✨ Overview

**Kish Estate** is a modern real estate website concept created to demonstrate how a property agency can present its listings through a premium, interactive digital experience.

The project focuses on combining **luxury visual design, smooth animations, property discovery, and customer-focused interactions** into a single experience.

The goal was not simply to create a beautiful website, but to explore how a real estate platform can make it easier for visitors to:

* Discover properties
* Search and filter listings
* Explore detailed property information
* Compare properties
* Save favorite properties
* Contact real estate agents
* Explore different areas of Kish Island
* Request consultation

---

## 🎯 Project Goals

The main goals of this project were:

* Create a premium digital identity for a real estate brand
* Provide an engaging property browsing experience
* Make property information easy to explore
* Create clear paths from property discovery to contacting an agent
* Demonstrate modern web design and interactive animations
* Build a responsive experience for both desktop and mobile users
